# NassauTickets

## Sobre o projeto

O **NassauTickets** é um sistema de gerenciamento de filas e atendimento, desenvolvido com o objetivo de organizar a emissão e a chamada de senhas, facilitar o trabalho dos atendentes e tornar o processo de atendimento mais eficiente.

O sistema permite acompanhar o fluxo das senhas, controlar os atendimentos e registrar as ocorrências durante o processo.

## Objetivo

Desenvolver uma solução que facilite o gerenciamento de filas, organize a ordem de atendimento e permita o acompanhamento das senhas emitidas, contribuindo para a organização e a eficiência do serviço.

## Funcionalidades

- Emissão de senhas para atendimento.
- Organização das senhas em filas.
- Gerenciamento de prioridades.
- Chamada de senhas pelos atendentes.
- Registro dos atendimentos realizados.
- Registro de não comparecimento.
- Acompanhamento do status das senhas.
- Geração de relatórios de atendimento.
